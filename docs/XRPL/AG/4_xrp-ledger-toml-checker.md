# xrp-ledger.toml Checker

If you run an XRP Ledger validator or use the XRP Ledger for your business,
                    you can provide information about your usage of the XRP Ledger to the world in a machine-readable xrp-ledger.toml file.

`xrp-ledger.toml`


#### Look Up By Domain

This tool allows you to verify that your xrp-ledger.toml file is syntactically correct and deployed properly.

`xrp-ledger.toml`


#### Look Up By Account

Enter an XRP Ledger address to see if that account is claimed by the domain it says owns it.
